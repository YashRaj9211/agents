# Job application preparation

Prepare an application using the candidate's supplied profile and resume.

1. Read files from `input/` and the job description in the browser.
2. Do not invent facts or answers.
3. You may create tailored HTML/CSS documents under `output/` and convert them to PDF.
4. Fill supported fields only.
5. Never submit. Stop at the review page and report unanswered questions and generated files.
